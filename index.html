How it works!

The Cover Image hides the Secret Image within itself

The Secret Image contains the you want to hide

The Least Significant Bits (LSB) are the last bits in each RGB channel of the cover image modifying them causes the smallest change in colour

The Most Siginificant Bits (MSB) are the start bits in each RGB channel of the cover image modifying them causes a significant change in colour

Using this principle, we take the MSB of the Secret Image into the LSB of the Cover Image

The end result is a Stego Image that is perceptually indistinguishable from the Cover Image
